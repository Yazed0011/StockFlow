# StockFlow
StockFlow API is a simple RESTful backend for managing small-business inventory, invoices, products, categories, suppliers, and stock movements (in/out).
It is built with pure PHP and MySQL using PDO, JWT-based authentication, and JSON responses, with a focus on clear business logic and transactional safety for critical operations like stock and invoice creation.
Main features:
Secure JWT authentication middleware.
CRUD APIs for products, categories, suppliers, and invoices.
Stock movement system (in / out) with validation and transaction handling.
Clean JSON responses and basic input validation on all endpoints.
